COMO ABRIR NO NETBEANS

1) Extraia o ZIP.
2) NetBeans > File > Open Project.
3) Selecione a pasta CadastroAlunosNetBeans_NOVO.
4) Clique em Open Project.
5) Em Source Packages > cadastroalunosnetbeans, abra CadastroAlunosNetBeans.java.
6) Pressione F6 para executar.

O projeto contém:
- Aluno.java
- TelaCadastroAluno.java
- CadastroAlunosNetBeans.java
- nbproject
- build.xml

O JTextArea mostra um aluno por linha, com atributos separados por ponto e vírgula.
