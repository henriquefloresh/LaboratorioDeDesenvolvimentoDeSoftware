CADASTRO DE ALUNOS - NETBEANS

Arquivos principais:
- src/javaapplication2/Aluno.java
- src/javaapplication2/CadastroAluno.java
- src/javaapplication2/JavaApplication2.java

COMO USAR NO PROJETO DO GITHUB:
1. Abra JavaApplication2 no NetBeans.
2. Dentro do pacote javaapplication2, crie/cole Aluno.java e CadastroAluno.java.
3. Substitua o conteúdo de JavaApplication2.java pelo arquivo fornecido.
4. Execute JavaApplication2.java ou CadastroAluno.java.

A tela é construída por Swing no método initComponents().
O TextArea mostra cada aluno em uma linha e separa os atributos com ponto e vírgula (;).
A matrícula é verificada para não permitir duplicidade.
